# Dottie

A macOS app, CLI, MCP server and web player for sketchy or clean diagrams stored as `.dottie` files.

## Language

### Reusable content

**Stencil**:
Ready-made artwork that is copied into a document as plain elements, with no link back to where it came from.
_Avoid_: template, shape (for the artwork itself)

**Symbol**:
A definition inside a document whose instances are expanded into elements each time they are drawn.
_Avoid_: component

**Script**:
A one-off JavaScript program run against a document with the `dottie` object.
_Avoid_: macro, extension

### Extensions

**Extension**:
An installed `.dottieext` bundle that adds extension shapes and commands to Dottie.
_Avoid_: plugin, add-on

**Extension shape**:
A path element generated by an extension from parameters, which remembers the extension and parameters that made it.
_Avoid_: custom shape, smart shape

**Command**:
A named action an extension adds to the menus that changes the document.
_Avoid_: action, effect

**Handle**:
An on-canvas knob an extension shape declares for adjusting one of its parameters by dragging.
_Avoid_: adjustment point, knob
