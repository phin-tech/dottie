# Dottie

A macOS app, CLI, MCP server and web player for sketchy or clean diagrams stored as `.dottie` files.

## Language

### Reusable content

**Stencil**:
Ready-made artwork that is copied into a document as plain elements, with no link back to where it came from.
_Avoid_: template, shape (for the artwork itself)

**Symbol**:
A definition inside a document whose instances are expanded into elements each time they are drawn.
_Avoid_: component

**Script**:
A one-off JavaScript program run against a document with the `dottie` object.
_Avoid_: macro, extension

### Connectors

**Waypoint**:
A point on the canvas that a connector's line passes through, placed by dragging the line. The app calls it a bend.
_Avoid_: control point (that is a pen stroke's), vertex

**Hop**:
The small arc a connector draws where it crosses a connector beneath it, so the two read as unconnected.
_Avoid_: jump, bridge, crossover

### Extensions

**Extension**:
An installed `.dottieext` bundle that adds extension shapes and commands to Dottie.
_Avoid_: plugin, add-on

**Extension shape**:
A path element generated by an extension from parameters, which remembers the extension and parameters that made it.
_Avoid_: custom shape, smart shape

**Extension tool**:
A drawing tool an extension adds to the toolbar, whose JavaScript turns a press and drag into plain elements that keep no tie to the extension.
_Avoid_: brush, plugin tool

**Command**:
A named action an extension adds to the menus that changes the document.
_Avoid_: action, effect

**Adjustment handle**:
An on-canvas control an extension shape declares for adjusting one of its parameters by dragging.
_Avoid_: handle (that also means the resize and rotation handles), knob, adjustment point

### Links

**Anchor**:
A name given to a shape so links can find it, from this drawing or another one; the Anchors tab lists them.
_Avoid_: section, bookmark

**Link**:
What a shape jumps to in the same drawing (`link`): another shape, on this page or another.
_Avoid_: reference, jump target

**Outside link**:
Where a shape leads out of the drawing (`url`): a web or mail address, or another drawing with an optional `#anchor` or page.
_Avoid_: URL link, hyperlink, external link
