# Dottie

A macOS app, CLI, MCP server and web player for sketchy or clean diagrams stored as `.dottie` files.

## Language

### Reusable content

**Stencil**:
Ready-made artwork that is copied into a document as plain elements, with no link back to where it came from.
_Avoid_: template, shape (for the artwork itself)

**Symbol**:
A definition inside a document whose instances are expanded into elements each time they are drawn.
_Avoid_: component

**Script**:
A one-off JavaScript program run against a document with the `dottie` object.
_Avoid_: macro, extension

### Connectors

**Waypoint**:
A point on the canvas that a connector's line passes through, placed by dragging the line. The app calls it a bend.
_Avoid_: control point (that is a pen stroke's), vertex

**Hop**:
The small arc a connector draws where it crosses a connector beneath it, so the two read as unconnected.
_Avoid_: jump, bridge, crossover

**Palette**:
A theme's named colors (`accent`, `muted`, `danger`, `warning`, `success`, `info`, and a page's own). A fill,
stroke or text color given by name is a **palette color**: it changes when the palette does (ADR 0005).
_Avoid_: swatch set, color scheme

### Extensions

**Extension**:
An installed `.dottieext` bundle that adds extension shapes and commands to Dottie.
_Avoid_: plugin, add-on

**Extension shape**:
A path element generated by an extension from parameters, which remembers the extension and parameters that made it.
_Avoid_: custom shape, smart shape

**Extension tool**:
A drawing tool an extension adds to the toolbar, whose JavaScript turns a press and drag into plain elements that keep no tie to the extension.
_Avoid_: brush, plugin tool

**Command**:
A named action an extension adds to the menus that changes the document.
_Avoid_: action, effect

**Adjustment handle**:
An on-canvas control an extension shape declares for adjusting one of its parameters by dragging.
_Avoid_: handle (that also means the resize and rotation handles), knob, adjustment point

### Links

**Anchor**:
A name given to a shape so links can find it, from this drawing or another one; the Anchors tab lists them.
_Avoid_: section, bookmark

**Link**:
What a shape jumps to in the same drawing (`link`): another shape, on this page or another.
_Avoid_: reference, jump target

**Outside link**:
Where a shape leads out of the drawing (`url`): a web or mail address, or another drawing with an optional `#anchor` or page.
_Avoid_: URL link, hyperlink, external link

### Playing on the web

**Scene**:
A named moment on a page's timeline (a marker) where a click-through presentation stops, and what a click can jump to.
_Avoid_: slide, step, chapter

**Looping scene**:
A scene the players don't stop at: on reaching its end they go back to its start, until a click or next leaves it.
_Avoid_: loop marker, hold

**Variable**:
A named true-or-false value on a page (`variables`) that clicks set or toggle without touching the playhead.
_Avoid_: state flag, toggle (that is what a click does to one)

**Condition**:
An element's `when`: variable names joined by `!`, `&&` and `||`; the element is drawn only while it holds.
_Avoid_: rule, predicate, visibility expression

**Override**:
A change to one element while a condition holds (`overrides`): dimmed, relabelled, recolored, or a packet rerouted.
_Avoid_: variant, state style

**Flow**:
Traffic from a shape to the first of its destinations it can reach, routed afresh each frame over the connectors drawn.
_Avoid_: stream, packet rule

**Volume**:
How much a flow carries, in the page's own unit; packets are a picture of it.
_Avoid_: weight, rate, traffic amount

**Capacity**:
The most volume a connector or shape carries; what doesn't fit takes the next cheapest route or is backlog.
_Avoid_: limit, bandwidth

**Queue**:
A shape marked as where traffic waits: backlog collects at the nearest queue before whatever is full.
_Avoid_: buffer, holding area

**Backlog**:
Volume a flow can't place on any route with room: the rate the queue in front of the bottleneck grows at.
_Avoid_: blocked, dropped, overflow

**Delay**:
Seconds traffic stays inside a shape it passes through: processing, queueing, handling.
_Avoid_: dwell, latency (that is the whole route's transit)

**Depth**:
How much backlog has piled up at a shape: its backlog times the seconds since the page's state last changed.
_Avoid_: queue length, size

**Load**:
A connector's or shape's throughput over its capacity.
_Avoid_: utilization, usage

**Metric**:
A number worked out per frame from the flows and state: throughput, load, transit, share via backup, backlog, in flight.
_Avoid_: stat, measurement

**Gauge**:
A rectangle that shows one metric as a number, bar or dial, drawn as plain shapes when the page is posed.
_Avoid_: meter, widget, dial (that is one style)

**Simulation**:
Playing a page as `<dottie-player>` would, with no browser (clicks, waits, snapshots), to check an interactive page.
_Avoid_: dry run, test run
