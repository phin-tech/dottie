## Diagrams people poke while they keep playing

- **Page variables.** A page can have named on/off variables. A click can toggle or set them, and any shape,
  connector or packet can be shown only while a condition holds, like `down` or `!down && east`. The animation
  never stops: click a region to take it down, and its traffic reroutes while the dots keep flowing. Connectors go
  with a shape that is hidden.
- **Looping scenes.** A scene can loop: playing doesn't stop when it gets there, and it goes round from its end to
  its start until a click or Next leaves it. Turn it on with Loop This Scene on the scene's menu in the timeline.
- In the app, the Click section has **Toggles** and **Shown when**. The editor shows every element so each state
  stays editable; exports and previews show the starting values. The web page export and `<dottie-player>` change
  them on click.

## Layout

- Auto-layout and diagrams built from a list of nodes and edges keep connector labels off the shapes. Long
  edges get a lane of their own, and the gaps between rows grow to fit their labels.

## Command line, MCP and dottie.js

- `dottie render` and `dottie inspect` read the app's open copy of a drawing, unsaved edits included, and say so
  when it differs from the file. `--disk` reads the saved file.
- `dottie <command> --help` prints the usage instead of making a folder called `--help`.
- MCP: `set_variable`; `when` on `add_shape`, `add_connector`, `update_element` and `send_packet`; `click_set` and
  `click_toggle` on `update_element`; `loop` on `add_scene` and `update_scene`. `build_diagram` edges take look
  fields (dash, width, arrowheads, …), a stroke color and `when`. `export_animation` writes a `.png` of the poster
  frame. `list_elements` shows variables and conditions.
- Scripts: `dottie.scene()` returns the scene's name, which is what `click: {scene}` takes, and takes `{loop}`.
  New: `dottie.variable`, `dottie.variables` and `dottie.loopScene`; `when` on everything; `click: {set, toggle}`.
  A lookup that found nothing explains that elements a script gets back are snapshots: look them up again after
  an update.
- dottie.js 0.7.0 plays page variables and looping scenes. `<dottie-player>` has `variables` and `setState()`, and
  fires a `state` event when a click changes them.
- Files that use variables or looping scenes open in earlier versions with every element shown and scenes that stop.
