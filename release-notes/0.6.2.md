## Handwriting fonts

- **Three handwriting fonts.** Caveat (a quick pen), Patrick Hand (neat print) and Architects Daughter (draftsman's
  lettering) come with Dottie, free under the SIL Open Font License. Pick one for any shape, connector label, text
  box or note, in the Style tab's new Text section or the bar over the canvas. Caveat has a bold; the other two
  draw bold and italic as regular.
- **Text size**, in the same places: the bar's menu, or the Style tab's slider for any size.
- **Your own fonts.** The font menu lists every font on your Mac too. Dottie draws it, and exports name it but don't
  carry it, so someone without it sees Helvetica Neue.
- **They travel.** SVG and web page exports carry the handwriting fonts a drawing uses, so they look the same
  anywhere. PNG, PDF, GIF, MP4 and Lottie draw them as they look in Dottie.
- Files that set a font open in earlier versions in Helvetica Neue.

## Command line, MCP and dottie.js

- MCP: `font` and `font_size` on `add_shape`, `add_connector` and `update_element`, and `font` on `build_diagram`
  and `import_mermaid` for a whole diagram. A packet's label takes its connector's font.
- Scripts: `font` and `fontSize` with the other look fields, `font` on `dottie.build`, and both on the elements calls return.
- dottie.js 0.6.2 lays out and draws the handwriting fonts exactly as Dottie does. `<dottie-player>` loads the ones a
  drawing uses from `fonts/` beside its script (`dist/fonts` on npm); `dottie-compile` and `dottie render -f js` put
  them in the compiled file. A connector label's box is no longer a point short at some text sizes.
- Skills for agents: `npx skills add phin-tech/dottie` installs `dottie` (MCP, the command line and scripting) and
  `dottie-extension`.
