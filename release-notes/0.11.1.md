## Drawings people drill into, on the web

- **Export every page as a web page.** File ▸ Export Pages as Web Page makes one HTML file holding every page, or
  a folder with `index.html` for the first page and a file for each other page. A shape that links to a shape on
  another page opens that page when clicked, so an overview can lead into its details.
- **Back works.** In the single file each page has its own address (`site.html#Billing`), so the browser's Back
  and Forward go between pages and a link can open any of them. In the folder, links are ordinary pages.
- **Drill in.** For agents, `drill_in` makes a shape lead to a page of its own: it adds the page (or uses the one
  named), a title the link lands on, and a "← Overview" shape that leads back.
- `simulate` follows links to other pages and takes a `back` step, and a recording follows along, so a drill-in
  path can be checked before exporting. `dottie simulate` takes `--back`.
- For agents and scripts: `export_animation` takes `pages: all` or `split`, and `dottie render` takes
  `--all-pages` and `--split`. Neither needs an animation.

## dottie.js

- `<dottie-player>` takes `history` (each page shown gets its own address) and `links` (where a page exported on
  its own finds the others), and fires `page` when the page shown changes.
- `dottie-compile --all-pages` puts every page in the compiled script.
